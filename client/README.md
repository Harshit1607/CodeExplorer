# CodeExplorer Client

Vite + React dashboard for visualizing repository analysis results from the CodeExplorer backend.

## Features

- **Real-time Pipeline**: Watch the analysis progress through 4 stages with a live progress bar and activity log
- **Streaming Results**: Results populate incrementally as the backend processes the repository (SSE)
- **AI Architecture Report**: Automated insights and high-level summaries generated by AI
- **Quick Start**: Install / build / run / test commands for each project in the repo (npm/pnpm/yarn, pip/uv/Poetry, Maven/Gradle, Cargo, CMake, Go)
- **Chat**: Retrieval-augmented Q&A with source chips linking to exact lines on GitHub
- **Search**: Hybrid semantic + keyword code search
- **Architecture**: Layered system diagram (ReactFlow)
- **Call Graph / File Dependencies**: Interactive D3.js graphs
- **Dependencies**: Grouped by ecosystem (Python, JavaScript, Java/Kotlin, Rust, C/C++, other)
- **Global Search** (Ctrl+K) across files, functions and classes
- **Dark/Light Mode**

## Tech Stack

- **Vite 5 + React 18** - build tool and UI
- **TypeScript** - Type-safe development
- **Tailwind CSS** - Utility-first styling
- **D3.js v7, ReactFlow, Recharts** - visualizations
- **Axios / EventSource** - HTTP and SSE communication

## Getting Started

### Prerequisites

- Node.js 18+ installed
- Backend API running (see `../README.md` / `../SETUP.md`)

### Installation

1. Install dependencies:
```bash
npm install
```

2. Create environment file:
```bash
cp .env.example .env.local
```

3. Update `.env.local` with your API URL:
```
VITE_API_URL=http://localhost:8000
```

### Development

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build

Create a production build (type-check + bundle into `dist/`):

```bash
npm run build
npm run preview   # serve the production build locally
```

## Usage

1. **Start the Backend**: Ensure the FastAPI backend is running on `http://localhost:8000`

2. **Enter Repository URL**: Input a public GitHub repository URL (e.g., `https://github.com/facebook/react`)

3. **Analyze**: Click "Analyze Repository" to start the **Streaming Analysis Pipeline**

4. **Watch Progress**: Monitor the 4-stage pipeline:
   - Stage 1: Meta Ingestion
   - Stage 2: Concurrent Scanning
   - Stage 3: Deep Analysis
   - Stage 4: AI Reporting

5. **View Results**: Browse through the 13 tabs: AI Report, Quick Start, Chat, Search, Architecture, Call Graph, Complexity, Overview, File Structure, Languages, Dependencies, File Dependencies, Key Files

## Environment Variables

| Variable | Description | Default |
|----------|-------------|---------|
| `VITE_API_URL` | Backend API URL | `http://localhost:8000` |

## Troubleshooting

**API Connection Error**
- Ensure the backend is running on the correct port
- Check that `VITE_API_URL` is set correctly (restart `npm run dev` after changing it)
- Verify CORS is enabled on the backend

**Build Errors**
- Clear the build output: `rm -rf dist`
- Reinstall dependencies: `rm -rf node_modules && npm install`
